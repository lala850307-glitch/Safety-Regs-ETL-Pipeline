# 工安違規數據處理管線 (Safety Regs ETL Pipeline)

這是一個基於 Python 與 Pandas 實作的輕量級資料處理管線（ETL Pipeline），專門用於自動化處理與分析工地安全違規紀錄，並產出易於閱讀的統計報表。

## 專案功能

- **資料轉換 (Transform)**：自動將原始的違規紀錄格式化，重新命名欄位，並將時間字串轉換為 DateTime 物件，進一步萃取日期、小時、星期等時間特徵。
- **數據統計與分析 (Analysis)**：自動計算並統計以下維度：
  - **違規類型**：各類違規事件（如未戴安全帽、未穿反光背心等）的數量與佔比。
  - **時段分析**：違規事件發生的熱門時段區間。
  - **工地統計**：各個工地的違規案件數分佈。
- **報表輸出 (Load)**：
  - 在終端機 (Console) 即時印出排版整齊的文字報表。
  - 匯出 **CSV 檔案** (`report-{時間}.csv`)，方便後續匯入 Excel 作進階分析。
  - 匯出 **TXT 文字檔** (`report_{時間}.txt`)，供紀錄留存。

## 檔案結構

- `main.py`：主程式進入點。定義 `ViolationAnalyzer` 類別，負責協調資料載入、處理與報表產出的整體流程。
- `date_processor.py`：資料處理模組。使用 Pandas 進行資料框 (DataFrame) 的清理與特徵工程。
- `report_generator.py`：報表生成模組。負責執行統計計算，並將結果輸出為文字報表及儲存為 CSV / TXT 檔案至 `report` 資料夾。
- `schemas.py`：資料存放區。目前包含測試用的原始字典列表資料 (`raw_events`)。

## 環境與套件需求

- Python 3.7+
- `pandas`

### 安裝依賴套件

請在終端機執行以下指令安裝需要的套件：

```bash
pip install pandas
```

## 使用方式

1. **準備目錄**：請確保在專案目錄下有一個名為 `report/` 的資料夾，以便程式存放生成的報表。
2. **執行程式**：在終端機中切換到專案目錄，並執行主程式 `main.py`：

```bash
python main.py
```

3. **查看結果**：
   - 終端機會直接顯示本次的違規統計數據。
   - 進入 `report/` 資料夾，即可找到以當下時間命名的 `.csv` 與 `.txt` 報表檔案。
